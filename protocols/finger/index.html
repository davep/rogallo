Finger

Introduction

Rogallo has support for displaying information returned from a Finger server.

finger:// URIs

Rogallo will handle any valid finger:// URI, either as a link to be followed from content returned by a Gemini, Spartan or Gopher server, or as entered in the command line.

Finger command

There is also support for a !finger command in the command line. The parameter it takes is the more traditional user@host format.

Note that this expects that the finger server is listening on port 79.
