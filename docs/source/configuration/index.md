# Introduction

The way that Rogallo works can be configured via a number of configuration
files found in the [configuration directory](directory.md), mostly broken
down by subject matter. You will find configuration information related to
user interface elements under each entry in the [UI
section](../ui/index.md).

Other configuration items can be found in this section:

- [Application command keyboard bindings](bindings.md)
- [Displayable content types](content_types.md)
- [General configuration](general.md)
- [Gopher-specific configuration](gopher.md)
- [Icon configuration](icons.md)
