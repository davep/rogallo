# Rogallo Example Themes

## Introduction

This directory contains a collection of example color themes for Rogallo,
featuring classic CRT terminal display styles, retro 8-bit microcomputer
palettes, and vintage IDE aesthetics.

## Themes Overview

| File                                           | Internal Name             | Mode  | Style & Aesthetics                                                                                                         |
|------------------------------------------------|---------------------------|-------|----------------------------------------------------------------------------------------------------------------------------|
| [`amber.json`](./amber.json)                   | `terminal-amber`          | Dark  | Warm monochrome amber CRT monitor aesthetic with glowing orange-amber text on a pitch-black background.                    |
| [`cbm64.json`](./cbm64.json)                   | `micro-cbm64`             | Dark  | Nostalgic Commodore 64 microcomputer style featuring classic light purple/blue text over a dark navy background.           |
| [`cyan.json`](./cyan.json)                     | `terminal-cyan`           | Dark  | High-contrast neon cyan CRT terminal display with vibrant aqua accents on a black background.                              |
| [`green.json`](./green.json)                   | `terminal-green`          | Dark  | Iconic green-screen monochrome monitor aesthetic with glowing matrix green text on a deep black background.                |
| [`speccy.json`](./speccy.json)                 | `micro-speccy`            | Light | ZX Spectrum 8-bit microcomputer style featuring primary red, cyan, and yellow accents on a clean light background.         |
| [`teletext.json`](./teletext.json)             | `teletext`                | Dark  | Vintage broadcast Teletext / Ceefax service aesthetic with ultra-high contrast yellow, cyan, and magenta on black.         |
| [`turbo.json`](./turbo.json)                   | `terminal-turbo`          | Dark  | Retro Borland Turbo C / Turbo Pascal IDE look with bright white text and yellow borders on a classic deep blue background. |
| [`white-inverted.json`](./white-inverted.json) | `terminal-white-inverted` | Light | High-contrast inverted light mode theme with dark charcoal text and borders on a soft grey background.                     |
| [`white.json`](./white.json)                   | `terminal-white`          | Dark  | Classic white-phosphor monochrome CRT monitor display with grayscale text on a black background.                           |

## Using

If you want to try any of these out, copy them into a `themes` directory
below where your Rogallo configuration file is stored.
